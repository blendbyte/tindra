# Security policy

## Supported versions

Security fixes are provided for the latest stable release of Tindra. Please
upgrade to that release before checking whether a reported issue still applies.
Older releases and development builds are not supported for security fixes.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/blendbyte/tindra/security/advisories/new).
If the form is unavailable, email security@blendbyte.com and ask for a private
channel before sending sensitive details.

Include the affected version, deployment details, steps to reproduce the issue,
and its potential impact. A minimal proof of concept is helpful, but please
remove credentials, personal data, and any information belonging to other users.

Please avoid public issues or pull requests that disclose a vulnerability before
a fix is available. We will review reports, discuss any additional information
needed, and coordinate disclosure and a fix with the reporter. Response and fix
times depend on the severity and complexity of the issue.
